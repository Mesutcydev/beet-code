## What is solid (re-verified)

- Permission gate: reads auto; writes/commands ask; `autoApproveCommands` is
  a **safe-command policy**, never a blanket shell bypass.
- Computer-use *actions* always ask: they are `.execute` but have no
  `command` argument, so `PermissionGate` cannot auto-approve them even when
  “Auto-approve safe commands” is on.
- Workspace realpath confinement, checkpoint-before-mutation, session
  AES-GCM + Keychain, hook fail-open / cannot bypass the gate.
- Local API server binds loopback only (`127.0.0.1` / `::1`).
- Browser JS injection boundary (`jsLiteral`) is tested.
