## Confirmed solid (read and verified)

- **PermissionGate** (`PermissionGate.swift`): reads auto; writes/commands gate on explicit flags; `.none` risk → needsApproval. No bypass path found.
- **ToolExecutor** (`ToolExecutor.swift`): duplicate-registration precondition, typed `ToolFailure` classification, failures never cached, typed exit-code path for `CommandExecuting`.
- **CommandPolicy**: exact-token executable match (no `ls-malicious` collision), 15 forbidden shell operators, workspace path containment on path-like args.
- **Checkpoint-before-mutation**: loop snapshots before `.write`/mutating commands; checkpoint failure aborts the mutation (fail-closed).
- **Verification-before-completion**: with `verifyAfterEdits`, a completion claim while the last build fails is refused and diagnostics fed back.
- **Context compaction**: assistant/tool pairing preserved; old tool outputs stubbed in place.
- **Workspace confinement**: realpath containment, symlink-safe, sibling-prefix refusal (covered by WorkspaceTests, all green).
- **Secrets**: Keychain-only for provider/HF/session keys; session payload redaction; no hardcoded keys in App/Core/CLI (scanned).
