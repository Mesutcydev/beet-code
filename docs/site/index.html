03 · Request logic

Stateless at the edge, serialized at the core.

The local API accepts complete conversations. The shared model engine is reset and replayed for each request, with a gate covering the full generation—including streaming.

AHTTP clientJSON or SSE request
↓
BAuthenticationBearer token except health
↓
CRequest gateone engine mutation at a time
↓
DReset + replayfull conversation restored
↓
EGenerate / streamrelease gate after response
↗

Why the gate exists

MLX, GGUF, and remote engines keep mutable session state. Without serialization, request A can reset or append turns while request B is generating.

⌁

Why CORS is opt-in

Loopback is not the same as browser isolation. A website can reach local ports when CORS permits it, so origins must be explicitly allowlisted.

▣

Why saves fail closed

A session contains conversation and tool history. Writing plaintext during a Keychain failure would silently violate the storage contract.
